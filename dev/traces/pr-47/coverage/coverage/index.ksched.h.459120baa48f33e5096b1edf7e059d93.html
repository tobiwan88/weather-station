211 /**
212 * Wake up a thread pending on the provided wait queue
213 *
214 * Given a wait_q, wake up the highest priority thread on the queue. If the
215 * queue was empty just return false.
216 *
217 * Otherwise, do the following, in order, holding _sched_spinlock the entire
218 * time so that the thread state is guaranteed not to change:
219 * - Set the thread's swap return values to swap_retval and swap_data
220 * - un-pend and ready the thread, but do not invoke the scheduler.
221 *
222 * Repeated calls to this function until it returns false is a suitable
223 * way to wake all threads on the queue.
224 *
225 * It is up to the caller to implement locking such that the return value of
226 * this function (whether a thread was woken up or not) does not immediately
227 * become stale. Calls to wait and wake on the same wait_q object must have
228 * synchronization. Calling this without holding any spinlock is a sign that
229 * this API is not being used properly.
230 *
231 * @param wait_q Wait queue to wake up the highest prio thread
232 * @param swap_retval Swap return value for woken thread
233 * @param swap_data Data return value to supplement swap_retval. May be NULL.
234 * @retval true If a thread was woken up
235 * @retval false If the wait_q was empty
236 */
237 bool z_sched_wake(_wait_q_t *wait_q, int swap_retval, void *swap_data);

319 /**
320 * @brief Walks the wait queue invoking a callback on each waiting thread
321 *
322 * This function walks the wait queue invoking the `walk_func` callback function
323 * on each waiting thread (except if stopped earlier by a non-zero return value),
324 * followed by a single call of `post_func`, all while holding `_sched_spinlock`.
