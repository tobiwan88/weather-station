100 /* --------------------------------------------------------------------------
101 * Q31 conversion helpers
102 * --------------------------------------------------------------------------
103 * Q31 range: [INT32_MIN, INT32_MAX] represents [-1.0, +1.0).
104 * We map the physical range onto this interval.
105 *
106 * Temperature: phys ∈ [-40, +85] °C, span = 125 °C
107 * encode: q31 = (t_c + 40.0) / 125.0 * INT32_MAX
108 * decode: t_c = (double)q31 / INT32_MAX * 125.0 - 40.0
